## 2. The Four Pillars of Kontyra Design

1. **Precision Black & White Foundation:** Pure black background (`#000000`), subtle glass surfaces (`bg-white/[0.02]`), and crisp border outlines (`border-white/[0.08]`).
2. **Harmonious Typography:** Native high-performance system typography stacks delivering zero cumulative layout shift and high readability.
3. **Seamless Cross-Ecosystem Navigation:** Identical top-bar navigation height (`56px`), mobile drawer patterns, and instant cross-links across all Kontyra subdomains.
4. **Autonomous Product Domains:** DevOS, Identity, VUX, KORA AI, VyntaJobs, and Console retain functional autonomy and domain accents while adhering to the core identity.
