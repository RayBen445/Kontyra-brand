# Kontyra Product Design & Development Standard

## 1. Objective
Establish a unified engineering and visual standard across every digital product built under Kontyra.

Every Kontyra product must feel like part of the same ecosystem without looking like an undifferentiated clone.

> **Core Axiom:** One ecosystem, distinct products, consistent experiences.

---

## 2. Shared Ecosystem Foundations (Mandatory for all Products)

1. **Logo Mark:** Official vector SVG mark (`/kontyra-icon.svg`) placed at the left of the navbar.
2. **Navigation Height & Placement:** Fixed or sticky top bar at precisely `56px` (`h-14`) with `border-b border-white/[0.08]` and background blur (`backdrop-blur-xl bg-black/80`).
3. **Typography Standard:** Native Apple/BlinkMacSystemFont system stack with SF Mono for code and technical badges.
4. **Surface Language:** Deep black root (`#000000`), glass card containers (`bg-white/[0.02] border border-white/[0.08]`), and crisp interactive borders.
5. **Ecosystem Cross-Links:** Standard ecosystem switcher in mobile drawer and footer linking:
   - `Docs` (`docs.kontyra.name.ng`)
   - `Blog` (`blog.kontyra.name.ng`)
   - `Legal` (`legal.kontyra.name.ng`)
   - `Console` (`console.kontyra.name.ng`)
   - `DevOS` (`devos.kontyra.name.ng`)

---

## 3. Product Specific Standards

### DevOS (`devos.md`)
- **Domain:** Developer Cloud IDE & Runtime
- **Accent:** Electric Blue (`#079BFF`)
- **Key Features:** Monaco editor, isolated terminal container, deployment status logs, edge port forwarding.

### Kontyra Identity (`identity.md`)
- **Domain:** Security & SSO Layer
- **Accent:** Trust Emerald (`#10B981`)
- **Key Features:** WebAuthn / FIDO2 passkeys, zero-knowledge credentials, multi-tenant RBAC, unified billing invoices.

### KORA AI (`kora-ai.md`)
- **Domain:** Neural Foundation Model & Autonomous Workflows
- **Accent:** Neural Magenta (`#B000D5`)
- **Key Features:** Streaming multi-turn chat, syntax-aware code generation, model context selector, token metrics.

### VUX Events (`vux.md`)
- **Domain:** Live Events, Ticketing & Access
- **Accent:** Ticket Coral (`#F43F5E`)
- **Key Features:** Cryptographic dynamic QR tickets, door scanner validation, seat tier selection, real-time checkout.

### VyntaJobs (`vyntajobs.md`)
- **Domain:** Freelance & Professional Escrow Marketplace
- **Accent:** Escrow Amber (`#F59E0B`)
- **Key Features:** Escrow contract rooms, milestone approvals, verified dev portfolios, dispute resolution.

### Kontyra Console (`console.md`)
- **Domain:** Central Multi-Tenant Administration
- **Accent:** Neutral Platinum (`#E4E4E7`)
- **Key Features:** API key generation, quota analytics, audit logs, team seat management.

### Docs (`docs.md`)
- **Domain:** Technical Reference & System Architecture
- **Key Features:** Sticky sidebar group navigation, search modal, copyable code blocks, terminal mockups.

### Blog (`blog.md`)
- **Domain:** Editorial, Articles & Stories
- **Key Features:** Curated sections, TTS voice listener, topic switcher tabs, Google Discover schema.

### Legal (`legal.md`)
- **Domain:** Governance, Policies & Terms
- **Key Features:** Long-form high-contrast text, legal version badges, table of contents, copy license button.

### Velopay (`velopay.md`)
- **Domain:** Financial Infrastructure
- **Accent:** Transaction Slate (`#38BDF8`)
- **Key Features:** Transfer ledger, virtual card controls, KYC verification, payout webhooks.

### Hearth (`hearth.md`)
- **Domain:** Quiet, Algorithm-Free Social Spaces
- **Accent:** Hearth Warmth (`#FB923C`)
- **Key Features:** Private circles, chronological feeds, direct media sharing, privacy locks.
