## 2. 3-Column Layout Architecture

- **Left Rail (Sticky Group Navigation):**
  - Search trigger (`Cmd + K`) at the top.
  - Hierarchical categories: `Getting Started`, `Core Identity`, `DevOS IDE`, `KORA AI`, `VUX Events`, `REST API`, `CLI Tools`.
- **Center Canvas (Markdown Content):**
  - High-readability font stack (`Inter` / system sans-serif with `1.75` line height).
  - Copyable terminal code blocks with language pills.
  - Interactive callout alerts (`Note`, `Tip`, `Important`, `Warning`, `Caution`).
- **Right Rail (Table of Contents):**
  - Auto-generated from active page headings (`h2`, `h3`).
  - Active scroll spy indicator highlighting the section currently in view.
