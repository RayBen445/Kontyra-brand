## 2. Visual & Architectural Grammar

- **Neural Accent Gradient:** Linear gradient from Deep Violet (`#7C3AED`) to Electric Magenta (`#D946EF`).
- **Streaming Telemetry & Thought Bubbles:**
  - Token streaming with smooth character rendering.
  - Collapsible internal monologue reasoning blocks (`thinking...`) styled with subtle dashed hairline borders (`border-dashed border-white/10`).
- **Syntax-Aware Code Blocks:**
  - High-contrast syntax highlighting using Prism / Shiki.
  - Integrated copy button, language indicator badge, and direct **"Open in DevOS IDE"** action trigger.
- **Model Selector & Token Metrics:**
  - Context window usage bar (e.g. `12.4k / 128k tokens`).
  - Latency and throughput indicator (`48 tokens/sec`).
